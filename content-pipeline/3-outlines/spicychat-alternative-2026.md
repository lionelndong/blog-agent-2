## Memory vs context window: why SpicyChat forgets [GAIN]

**Target:** ~400 words

- **BLUF:** "SpicyChat has weak memory" is imprecise — what it actually has is a *context window*, a fixed amount of recent text the model can see at once (4K–16K tokens), which is a fundamentally different thing from persistent cross-session memory that survives between chats. (This is the ONE place the 4K/8K/16K mechanism is explained — "Why switch" only named the symptom.)
- **Context window = short-term:** the model reads the most recent N tokens of the current chat. Once you pass that limit, the oldest messages scroll out and are gone — which is exactly why long stories drift and characters forget what you told them an hour ago.
- **Persistent memory = long-term:** a separate store of who the character is and what happened, retrieved into each new session — so the companion remembers across days, not just within one window.
- SpicyChat's tiers map straight to this: 4K (free/Get-a-Taste) → 8K (True Supporter) → 16K (I'm All In). More tokens delay the drift; none of them make memory persistent.
- This is the one genuine wedge of the whole article: the alternatives worth switching to are the ones that add persistent memory on top of a usable window.
